# Changelog

## 1.0.0

Initial Hex release of `jido_chat_slack`.

### Features

- Adds the Slack adapter package for `jido_chat`.
- Provides the canonical `Jido.Chat.Slack.Adapter` implementation backed by Slack HTTP APIs and `Req`.
- Supports Slack message operations, webhook and Socket Mode ingress, reactions, and file uploads.
